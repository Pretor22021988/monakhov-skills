# Российские научные источники

Международные инструменты поиска литературы (OpenAlex, Crossref, Semantic
Scholar) русскоязычную научную периодику не индексируют. Этот скилл закрывает
пробел.

## Три источника, три разных жанра

| Источник | Что даёт | Когда особенно полезен |
|---|---|---|
| `cyberleninka` | статьи из журналов открытого доступа | текущая дискуссия по теме |
| `neb` | монографии, сборники, издания из фондов РГБ | доктринальная опора |
| `dissercat` | диссертации и авторефераты | обзор степени разработанности |

**Автореферат — недооценённый источник.** Двадцать страниц, где автор сам
изложил положения, выносимые на защиту, плюс список литературы, который он
собирал три года. Один релевантный автореферат экономит день поиска.

## Как искать

```bash
python3 scripts/ru_sources_search.py "запрос"
```

По умолчанию опрашиваются все три источника, **по всему архиву без ограничения
по годам**. Это сделано намеренно: в правовой науке работа 2003 года может быть
основной по теме. Ограничивайте период только если пользователь прямо попросил.

| Ключ | Что делает |
|---|---|
| `--sources cyberleninka,neb` | ограничить набор источников |
| `--pages N` | страниц выдачи на источник (по умолчанию 2) |
| `--since ГОД` / `--until ГОД` | ограничение периода, **по умолчанию выключено** |
| `--format text\|json\|gost` | вид вывода; `gost` даёт черновой список литературы |
| `--delay СЕК` | пауза между запросами (по умолчанию 1.5) |
| `--html-file ФАЙЛ --source КЛЮЧ` | разобрать сохранённую страницу |

## Как формулировать запрос

Морфология поддерживается, склонять не нужно. Работает на терминах, а не на
длинных фразах.

Хорошо: `субсидиарная ответственность контролирующих лиц`
Плохо: `какая сейчас практика по субсидиарной ответственности директоров`

Мало результатов — уберите уточняющие слова. Слишком много — добавьте
отраслевой термин, а не общий («банкротство» → «банкротство застройщика»).

Полезный приём: искать один смысл разными терминами, принятыми в разных школах,
и объединять выдачи. «Освобождение от долгов», «списание задолженности» и
«недобросовестность должника» дадут пересекающиеся, но не совпадающие списки.

## Что делать с результатами

1. Отбирайте по названию и аннотации, а не по позиции в выдаче — сортировка
   идёт по релевантности движка, а не по качеству работы.
2. **Читайте полный текст, прежде чем ссылаться.** Никогда не пересказывайте
   работу по одной аннотации и не приписывайте автору выводов, которых вы не
   видели в тексте.
3. Для списка литературы — тот же запрос с `--format gost`.

## Ограничения — говорить о них пользователю

- **Разбор выдачи приблизительный.** Название и ссылка извлекаются надёжно.
  Авторы, издание и год — по мере наличия в разметке; часть записей придёт без
  них. Для сносок эти поля проверяются по карточке работы.
- **`--format gost` — черновик.** Нет страниц, часто нет авторов и номера
  выпуска. Дозаполняется вручную, см. `references/gost.md`.
- **Сайт может ответить 403 или 429** при частых запросах, через прокси или из
  облачной среды. Увеличьте `--delay`, повторите позже либо сохраните страницу
  выдачи и разберите через `--html-file`.
- **Разметка может измениться.** Если источник вернул пусто при заведомо
  рабочем запросе — причина почти всегда в этом. Скрипт скажет об этом сам.
  Чинится правкой `link_re` в словаре `SOURCES` в начале скрипта — по одной
  строке на источник.
- **Это не весь корпус.** Значительная часть журналов перечня ВАК доступна
  только в eLibrary по подписке; коннектора к ней не существует. Отсутствие
  результата здесь не означает, что по теме не писали.

## Чего делать нельзя

Не выдавать найденное за исчерпывающий обзор литературы. Не ставить ссылку на
работу, полный текст которой не прочитан. Не поднимать `--pages` до десятков
ради полноты — это нагрузка на бесплатные открытые ресурсы; разумный предел
5 страниц на источник.
