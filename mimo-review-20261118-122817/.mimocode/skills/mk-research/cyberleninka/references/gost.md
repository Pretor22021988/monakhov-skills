# ГОСТ Р 7.0.5-2008: формы записи для электронных статей

Скрипт с ключом `--format gost` собирает черновик по схеме ниже. Поля, которых
нет в выдаче, придётся дозаполнить со страницы статьи.

## Статья в журнале, взятая из открытого доступа

    Фамилия И. О. Название статьи // Название журнала. — Год. — № выпуска. —
    С. 00–00. — URL: адрес (дата обращения: ДД.ММ.ГГГГ).

Пример полностью заполненной записи:

    Иванов И. И. Освобождение гражданина от обязательств при завершении
    процедуры реализации имущества // Вестник гражданского права. — 2021. —
    № 3. — С. 45–67. — URL: https://cyberleninka.ru/article/n/... (дата
    обращения: 12.03.2026).

## Что скрипт заполнить не может

| Поле | Почему |
|---|---|
| Авторы | в выдаче присутствуют не всегда |
| Номер выпуска | в выдаче отсутствует |
| Страницы | в выдаче отсутствуют |

Всё это есть на самой странице статьи и в PDF. Для списка из пяти-семи позиций
дозаполнение занимает несколько минут; автоматизировать его по выдаче нельзя
без обхода каждой карточки.

## Подстрочные ссылки

Для сносок в тексте применяется та же схема, но с указанием конкретной
страницы, на которую вы ссылаетесь, вместо диапазона страниц статьи:

    Иванов И. И. Указ. соч. С. 52.

## Частые ошибки

- Дата обращения обязательна для электронного ресурса — без неё запись
  неполная.
- Знак «//» отделяет статью от источника; перед ним точка не ставится.
- Тире в записи — длинное («—»), а не дефис.
- Если у статьи есть DOI, его указывают вместо URL или вместе с ним; DOI
  устойчивее ссылки.
