# Поиск в КиберЛенинке

КиберЛенинка — открытая российская научная библиотека. Полные тексты доступны
бесплатно, поиск идёт по названиям, авторам, аннотациям, ключевым словам и
распознанным текстам, с поддержкой русской морфологии.

Этот скилл закрывает пробел, которого нет у международных инструментов поиска
литературы: они не индексируют русскоязычную научную периодику.

## Когда применять

Применяйте, если запрос касается:

- поиска русскоязычных научных статей по любой отрасли;
- подбора источников для статьи, заключения, диссертации или обзора литературы;
- проверки, что уже написано по теме в российской науке;
- сбора списка литературы с оформлением по ГОСТ.

Не применяйте для поиска судебной практики и нормативных актов — это другая
задача и другие источники. КиберЛенинка содержит научные публикации, а не
судебные акты.

## Как искать

Запустите скрипт:

```bash
python3 scripts/cyberleninka_search.py "запрос"
```

Поиск по умолчанию идёт **по всему архиву, без ограничения по годам**. Это
сделано намеренно: в правовой науке работа 2003 года может быть основной по
теме. Ограничивайте период только если пользователь прямо об этом попросил.

Ключи:

| Ключ | Что делает |
|---|---|
| `--pages N` | сколько страниц выдачи забрать, по умолчанию 3 (примерно 60 записей) |
| `--since ГОД` / `--until ГОД` | ограничение периода, **по умолчанию выключено** |
| `--format text\|json\|gost` | вид вывода; `gost` даёт черновой список источников |
| `--strategy auto\|api\|html` | способ получения данных, по умолчанию `auto` |
| `--delay СЕК` | пауза между страницами, по умолчанию 1 секунда |
| `--html-file ФАЙЛ` | разобрать сохранённую страницу вместо сетевого запроса |
| `--catalog vak,rsci,scopus` | только журналы перечней ВАК, РИНЦ, Scopus; **по умолчанию выключено** |
| `--fulltext N` | для первых N результатов (не больше 10) скачать полный текст: `.txt` из страницы статьи и `.pdf` |
| `--save-dir ПАПКА` | куда класть полные тексты, по умолчанию `./cyberleninka_fulltext` |

## Фильтр по перечням

`--catalog vak` оставляет только статьи из журналов перечня ВАК (`rsci` — РИНЦ,
`scopus` — Scopus, можно через запятую). Применяйте, когда источник нужен для
диссертации, журнала из перечня ВАК или когда важен вес издания.

Фильтр идёт через недокументированный параметр API, поэтому скрипт каждый раз
проверяет его сам: сравнивает число находок с фильтром и без, а затем сверяет
метку перечня на странице первой статьи. Если фильтр не сработал или код ведёт
на другой перечень, скрипт завершается с кодом 3 и ничего не выводит —
неотфильтрованную выдачу за отфильтрованную не выдаёт. В этом случае ищите без
`--catalog` и смотрите метки через `--fulltext`.

## Полный текст

Правило «не ссылаться на работу, которую не прочитал» выполняется через
`--fulltext N`: для первых N результатов скрипт сохраняет текст статьи (`.txt`,
если он есть в разметке страницы) и PDF, а в выдаче показывает метки перечней
(ВАК, РИНЦ, Scopus) с самой страницы статьи. Читайте сохранённый текст, прежде
чем ссылаться. Пауза между загрузками — та же `--delay`.

## Как формулировать запрос

Морфология поддерживается, поэтому склонять слова не нужно. Работает лучше
всего на терминах, а не на длинных фразах.

Хорошо: `субсидиарная ответственность контролирующих лиц`
Плохо: `какая сейчас практика по субсидиарной ответственности директоров`

Если результатов мало — уберите уточняющие слова. Если слишком много — добавьте
отраслевой термин, а не общий («банкротство» → «банкротство застройщика»).

Полезный приём: искать один и тот же смысл разными терминами, принятыми в
разных школах, и объединять результаты. Например, «освобождение от долгов»,
«списание задолженности» и «недобросовестность должника» дадут пересекающиеся,
но не совпадающие выдачи.

## Что делать с результатами

Скрипт возвращает название, ссылку, год и фрагмент аннотации, а в первой строке —
сколько всего работ по запросу в базе. Дальше:

1. Отберите релевантное по названию и аннотации, а не по позиции в выдаче —
   сортировка идёт по релевантности движка, а не по качеству работы.
2. Прочитайте полный текст (`--fulltext N` или по ссылке), прежде чем ссылаться. Никогда не
   пересказывайте статью по одной аннотации и не приписывайте автору выводов,
   которых вы не видели в тексте.
3. Для списка литературы запустите тот же запрос с `--format gost`.

## Ограничения, о которых нужно сказать пользователю

- **Разбор выдачи приблизительный.** Название и ссылка извлекаются надёжно.
  Журнал, авторы и год — по мере наличия в разметке; часть записей придёт без
  них. Для оформления сносок эти поля нужно проверять по странице статьи.
- **Вывод `--format gost` — черновик, а не готовый список.** Отсутствуют
  страницы, часто отсутствуют авторы. Перед сдачей текста поля дозаполняются
  вручную.
- **Сайт может ответить 403 или 429** при частых запросах, при работе через
  прокси или из облачной среды. В этом случае увеличьте `--delay`, повторите
  позже или сохраните страницу выдачи вручную и разберите через `--html-file`.
- **Разметка сайта может измениться.** Если поиск перестал возвращать
  результаты при заведомо рабочем запросе — причина почти всегда в этом.
  Сохраните страницу и проверьте через `--html-file`, затем поправьте
  регулярное выражение `ARTICLE_RE` в начале скрипта.
- **КиберЛенинка — не весь корпус.** В ней нет значительной части журналов из
  перечня ВАК, доступных только в eLibrary по подписке. Отсутствие результата
  здесь не означает, что по теме не писали.

## Чего делать нельзя

Не выдавайте найденное за исчерпывающий обзор литературы. Не ставьте ссылку на
работу, полный текст которой не прочитали. Не увеличивайте `--pages` до
десятков ради полноты — это создаёт нагрузку на бесплатный открытый ресурс;
разумный предел 5–10 страниц на запрос.
