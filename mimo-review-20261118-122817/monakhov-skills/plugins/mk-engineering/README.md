# mk-engineering

Инженерия: GitOps, Terraform, SLO и надёжность, влияние вместо инструментов.

| Скилл | Когда применяется |
|---|---|
| `gitops-deploy` | GitOps вместо ручного деплоя — желаемое состояние лежит в git, система приводится к нему одной воспроизводимой командой, откат — переход на предыдущий тег |
| `impact-over-tools` | Результат с цифрами вместо списка инструментов — превращает «Docker, Kubernetes, Terraform, Python, SQL» в достижения вида «сократил деплой с 40 до 8 минут через GitOps» для резюме, профиля LinkedIn или hh,… |
| `slo-reliability` | Надёжность с цифрами — SLI, SLO, бюджет ошибок, алерты по скорости сжигания бюджета и разбор инцидентов без поиска виноватых |
| `terraform-as-system` | Terraform как система, а не один большой main.tf — модули с явным интерфейсом, окружения отдельно, удалённое состояние с блокировкой, зафиксированные версии, plan на ревью до apply |

Установка в Claude Code (2.1.275+): `/plugin install mk-engineering --marketplace Pretor22021988/monakhov-skills`
