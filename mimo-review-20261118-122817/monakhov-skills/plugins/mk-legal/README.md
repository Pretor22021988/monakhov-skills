# mk-legal

Российское право: заключения, процессуальные документы, разбор актов и практики, договоры, критика позиции, ответы на площадках.

| Скилл | Когда применяется |
|---|---|
| `bevzenko` | Создание глубоких юридических заключений и правовых меморандумов в академическом стиле |
| `casuslegal-razbor` | Постатейный разбор обобщающего акта (Пленум ВС РФ, обзор практики ВС, обзор или справка СИП): каждый пункт сопровождается дословным тезисом, кратким разбором и подвязывается к актам-первоисточникам и практике… |
| `casuslegal-sudebny-dokument` | Подготовка готового к подаче процессуального документа (иск, отзыв, апелляционная или кассационная жалоба, заявление, ходатайство) с практикой высших судов РФ, СИП и КАС |
| `contract-review` | Review legal contracts, NDAs, employment agreements, SaaS terms, and M&A documents |
| `devils-advocate` | Режим «Адвокат дьявола» — жёсткая, беспощадная критика любой позиции, идеи, решения или документа |
| `general-counsel-advisor` | General Counsel advisory for startups: contract review (MSA, SaaS, NDA, DPA, employment), IP strategy, term sheet decoding, and regulatory landscape mapping |
| `legal-docs-ru` | Создание профессиональных юридических документов на русском языке — справки, заключения, аналитические записки, письма в трибуналы, отчёты |
| `otvety-na-ploshchadkah` | Ответы юриста на вопросы HARANT и 9111.ru через браузер пользователя — отбор вопросов по специализациям, ответы с проверенными нормами и практикой, публикация только после одобрения каждого ответа |
| `praktika-pod-tezisy` | Подбор судебной практики под набор правовых тезисов: по каждому тезису две подборки, подтверждающая (pro) и опровергающая или ограничивающая (contra), причём контр-практика ищется встречным переформулированным запросом |
| `proverka-akta` | Проверка судебного акта нижестоящего суда (решение, постановление или определение арбитражного суда либо суда общей юрисдикции) на соответствие практике высших судов РФ, СИП и коллегии по административным делам ВС |

Установка в Claude Code (2.1.275+): `/plugin install mk-legal --marketplace Pretor22021988/monakhov-skills`
